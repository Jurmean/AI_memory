# 算法调度层显化与增强

## 一、能力值衰减 -- 基于 FSRS 幂律遗忘曲线

### 1.1 理论依据

采用 FSRS（Free Spaced Repetition Scheduler）的幂律遗忘公式，替代简单指数衰减：

```
R(t) = (1 + F * t / S) ^ C
```

- `t` = 距上次学习的天数
- `S` = 稳定性（stability），单位：天。定义为 R 从 100% 降到 90% 所需时间
- `F = 19/81`（常数）
- `C = -0.5`（常数）

能力值 theta 的衰减公式：`theta_effective = theta_last * R(t)`

其中 `S` 可由用户整体的学习频率和正确率推算，初始默认 30 天（即 30 天后能力保留率降到 90%）。实际 S 会随答题记录动态调整。

### 1.2 实现：新增 `lib/core/algorithms/ability_decay.dart`

```dart
class AbilityDecay {
  static const double _f = 19 / 81;
  static const double _c = -0.5;

  static double retrievability(double daysSinceLastStudy, double stability) {
    if (daysSinceLastStudy <= 0) return 1.0;
    return pow(1 + _f * daysSinceLastStudy / stability, _c);
  }

  static double effectiveTheta(double theta, double daysSinceLastStudy, double stability) {
    return theta * retrievability(daysSinceLastStudy, stability);
  }

  static double estimateStability(double correctRate, int totalReviews) {
    // 基础稳定性 30 天，根据正确率和复习量调整
    return (30.0 * (0.5 + correctRate) * (1 + log(1 + totalReviews) / 5)).clamp(7.0, 365.0);
  }
}
```

### 1.3 首页与能力曲线详情页

- 首页"能力值 theta"卡片展示的是 `effectiveTheta`（衰减后），而非数据库中的原始 theta
- 点击该卡片进入新的**能力曲线详情页** `lib/features/ability/ability_detail_page.dart`：
  - 顶部：当前 effective theta + 衰减百分比 + 稳定性 S 值
  - 主体：fl_chart 绘制两条曲线
    - 蓝线：历史 session 的 theta 快照（已有数据）
    - 橙色虚线：从最后一个 theta 值开始的预测衰减曲线（未来 30 天）
  - 底部：关键指标卡片（S 稳定性、预计半衰期、距上次学习天数）

## 二、题库详细参数显化 -- 干扰项分析

### 2.1 Question 模型扩展

在 [lib/data/models/question.dart](lib/data/models/question.dart) 新增 `distractor_analysis_json` 字段：

```dart
class Question {
  ...
  final List<DistractorInfo>? distractorAnalysis;  // 新增
}

class DistractorInfo {
  final int optionIndex;
  final double attractiveness;  // 0.0 ~ 1.0，干扰吸引度
  final String? commonMistakeReason;  // 常见误选原因
}
```

数据库升级：`ALTER TABLE questions ADD COLUMN distractor_analysis_json TEXT`。

样例题目中填入预设干扰度数据（根据化学知识合理设定），例如：

- 某题选项 A 干扰度 0.3，原因："容易混淆分解反应与氧化还原反应"

### 2.2 题目详情页 `lib/features/question_bank/question_detail_page.dart`

从题库列表点击题目进入详情页，展示：

- **题干** + 选项（带正确标记）
- **基本参数卡片**：IRT 难度 b 值、来源、创建时间
- **知识点标签**：关联的所有知识点 Chip
- **干扰项分析卡片**：每个错误选项的干扰度条形图 + 误选原因说明
- **复习状态卡片**：当前 ReviewState（EF、间隔、下次复习日期、已复习次数）
- **答题历史**：该题的所有 AnswerLog，时间线展示

## 三、复习队列可视化

### 3.1 队列页面 `lib/features/queue/review_queue_page.dart`

从首页"待复习"卡片点击进入，展示排序后的完整复习队列：

- **顶部筛选栏**：按知识点/按难度/按到期时间筛选
- **列表项**：每题显示
  - 题干摘要（前 40 字）
  - 优先级分数条（可视化 priority 值）
  - 难度色标 + 到期状态标签（已逾期 N 天 / 今日到期 / 明日到期）
  - 知识点标签
- 点击题目进入题目详情页
- 底部悬浮按钮"开始复习"直接跳转 QuizPage

### 3.2 筛选逻辑

复用现有 `reviewQueueProvider` 数据，前端做筛选：

- 知识点筛选：通过 `question_kp` 表获取每题的知识点
- 难度筛选：按 difficultyB 范围过滤
- 到期筛选：overdueDays 分段
