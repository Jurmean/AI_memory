# 智能记忆助手系统优化计划

## 一、内置高中化学样例题目

在 `database_helper.dart` 的 `_onCreate` 方法末尾，插入一批预置数据：

- **10 道高中化学选择题**，覆盖：氧化还原反应、化学平衡、离子反应、有机化学基础、电化学等知识点
- **5-6 个知识点** (`knowledge_points` 表)，如"氧化还原反应"、"化学平衡"、"离子反应"、"有机化学"、"电化学"
- **知识点关联** (`knowledge_edges` 表)，建立合理的 related / prerequisite 关系
- **题目-知识点映射** (`question_kp` 表)
- **初始 ReviewState**，`nextReviewDate` 设为 `DateTime.now()` 使题目立即可复习
- 每道题的 `difficultyB` 参数设为 -1.0 到 1.5 之间的合理值（IRT 难度参数）

这样用户首次打开 App 就能看到题目并开始复习。

## 三、LLM 配置通用化（OpenAI 格式）

### 3.1 重命名 Client (`lib/llm/minimax_client.dart` -> `lib/llm/llm_client.dart`)

- 类名从 `MiniMaxClient` 改为 `LLMClient`
- 异常类从 `MiniMaxException` 改为 `LLMException`
- 默认 `baseUrl` 改为 `https://api.openai.com/v1/chat/completions`（标准 OpenAI 端点）
- 默认 `model` 改为 `gpt-3.5-turbo`
- API 调用格式已经是 OpenAI 兼容的，无需改动请求体结构

### 3.2 更新 Provider (`lib/providers/llm_provider.dart`)

- `LLMSettings` 增加 `baseUrl` 字段
- `SharedPreferences` 中存储/读取 `llm_base_url`
- Provider 名称从 `miniMaxClientProvider` 改为 `llmClientProvider`
- 默认 model 改为空字符串或通用名称

### 3.3 更新设置页 (`lib/features/settings/settings_page.dart`)

- 标题从 "MiniMax API 配置" 改为 "LLM API 配置"
- 增加 Base URL 输入框（带默认值提示）
- 增加 Model 名称输入框
- 提示文案去掉所有 "MiniMax" 字样

### 3.4 全局引用更新

- 所有 `import minimax_client.dart` 改为 `import llm_client.dart`
- 所有 `miniMaxClientProvider` 改为 `llmClientProvider`
- 所有 "MiniMax" 提示文案改为通用表述

## 四、设置中自定义 Prompt

### 4.1 扩展 LLMSettings

在 `LLMSettings` 中增加三个可选 prompt 字段：

- `customSystemPrompt`：覆盖 AI 助手的系统 prompt
- `customQuestionPrompt`：覆盖题目结构化的系统指令
- `customDiagnosisPrompt`：覆盖诊断报告的系统指令

使用 `SharedPreferences` 持久化。

### 4.2 设置页增加 Prompt 编辑区

- 新增 "Prompt 自定义" 卡片区域
- 每个 prompt 用 `ExpansionTile` 折叠显示
- 提供"恢复默认"按钮
- 显示当前 prompt 的前 N 个字符作为预览

### 4.3 Prompt 使用处适配

- `chat_prompt.dart` / `chat_service.dart`：优先使用自定义 prompt，fallback 到默认
- `question_structure_prompt.dart` / `question_structure_service.dart`：同上
- `diagnosis_prompt.dart` / `diagnosis_service.dart`：同上

通过 `ref.read(llmSettingsProvider)` 获取自定义 prompt，传入各 service。
